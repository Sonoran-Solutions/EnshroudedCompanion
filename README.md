# Enshrouded Companion

Planning repository for an experimental AI companion for Enshrouded: contextual roleplay, adventuring, combat assistance, and staged building support, with local or hosted model backends.

Status: documentation and feasibility planning only. No game integration, companion runtime, or playable mod is implemented or validated yet.

The implementation plan and supporting documentation will be proposed through a pull request. This project is unofficial and is not affiliated with or endorsed by Keen Games.
