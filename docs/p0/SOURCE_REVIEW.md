### ShroudForge

- **Guards:** [`Load`](https://github.com/bonsaibauer/shroudforge/blob/3ed90de1df266c4f0c217523a02a71dfa67243de/modules/game-runtime/native/profiles/select_game_profile.cpp) matches target, KFC format, PE timestamp/image size and optional SHA256; it checks approved provenance when present and rejects ambiguous exact profiles. It also deliberately permits manual or `allowStructuralRevalidation` fallback profiles. Therefore the stock loader is **not a universal unknown-build refusal gate**. [`EngineContext::Configure`](https://github.com/bonsaibauer/shroudforge/blob/3ed90de1df266c4f0c217523a02a71dfa67243de/modules/game-runtime/native/engine-context/configure_engine_layout.cpp) separately requires exact hash/timestamp/image size and validated ECS provenance. Hook read/installation sources check instruction matches. P0 must explicitly deny mismatched images before unsafe hooks; source inspection alone cannot certify all startup paths meet that requirement.
- **Observations:** [`KfcRuntimeEcsQuery` / `query_on_game_thread`](https://github.com/bonsaibauer/shroudforge/blob/3ed90de1df266c4f0c217523a02a71dfa67243de/modules/game-runtime/native/ecs/query_entities.cpp) implement bounded incremental discovery, current-epoch checks, generation-aware handles, cache revalidation and explicit incomplete/error sentinel results. [`KfcRuntimeEcsRead` / `KfcRuntimeEcsReadMany`](https://github.com/bonsaibauer/shroudforge/blob/3ed90de1df266c4f0c217523a02a71dfa67243de/modules/game-runtime/native/ecs/read_entity_components.cpp) implement native component reading. [`lua_ecs_read_fields`](https://github.com/bonsaibauer/shroudforge/blob/3ed90de1df266c4f0c217523a02a71dfa67243de/modules/mod-runtime/lua/ingame/ecs/access_component_fields.rs) supplies an implemented Lua path. Reflected field/type names must be discovered and validated; do not invent health/position component layouts. Owner account identity, persistent world identity, save rollback, quest scope, sequencing and reconnection still require separate proof.
- **Actor limitation:** [`WorldRuntime::SpawnEntity` / `KfcRuntimeWorldEntitySpawn`](https://github.com/bonsaibauer/shroudforge/blob/3ed90de1df266c4f0c217523a02a71dfa67243de/modules/game-runtime/native/building/spawn_building_prop.cpp) is explicitly a building-prop path.
